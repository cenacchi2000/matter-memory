02 / Remember

Cover the object.

A dashed amber box marks only its last observed location. It does not reveal the object through the obstruction. Missing detections can also be caused by model error or leaving the view.

03 / Verify

Reveal and confirm.

A same-category detection after loss becomes a candidate. Confirm its identity before it replaces the remembered object. Identical objects can confuse the detector.

Conversation

Working baseline: COCO-SSD MobileNet V2 detection + geometric association + last-observation memory. Responses are generated from these states using templates; there is no general conversational language model. The detector covers a fixed set of object categories. This prototype does not establish accurate hidden-object tracking, 3D reconstruction, or CVPR-level performance.

Camera processing and memory remain in this page; stopping releases the camera, reloading clears memory. Model files load from public CDNs. Optional speech uses your browser’s speech service and may depend on its provider. The independently authored avatar uses procedural geometry. Gaze follows the selected visible target; speech motion is procedural, not phoneme-aligned. No official robot control or trained policy is connected. Detector source.
